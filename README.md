# Banking System

A simple console-based Banking System developed using Java.

## About the Project

The Banking System is a menu-driven Java application that allows users to create a bank account and perform basic banking operations.

The project demonstrates Java programming concepts such as methods, conditional statements, loops, arrays, and ArrayList.

## Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* View account details
* View transaction history
* Menu-driven interface

## Technologies Used

* Java
* Scanner
* ArrayList
* Object-oriented programming concepts

## How to Run

### Prerequisites

Install Java JDK on your computer.

### Compile the Program

```bash
javac BankingSystem.java
```

### Run the Program

```bash
java BankingSystem
```

## How to Use

1. Run the program.
2. Enter the account holder's name.
3. Enter the account number.
4. Enter the initial deposit amount.
5. Select an operation from the banking menu.
6. Deposit or withdraw money.
7. Check the balance or view transaction history.
8. Select Exit to close the application.

## Future Improvements

* Store account information in a database
* Add multiple bank accounts
* Add PIN-based authentication
* Store transaction history permanently
* Add a graphical user interface

## Note

This is a beginner-level Java console application. Account information and transaction history are stored in memory and are reset when the program terminates.
